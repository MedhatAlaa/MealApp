# Meal APP 

Meal App  Using Cubit As State management with Dark Mode

 # Features used in app: 
- Clean Architecture Design Pattern
- MVVM - Model - View - View Model Pattern
- Dependency injection
- Application Layer
- Domain layer
- Data layer
- Presentation layer
- pub dev tools
- plugins
